# Web Api Timescale Data

Intern Task.

The goal is to develop Web-Api using .NET that has 3 methods:

[1] The first one allows you to upload your data (a .csv file in this case), validates the file and saves it to PostgreSQL DB. Also, it calculates some integral resluts and saves them to another table
[2] Second method is inteded to show records from the "Results" table with different filters
[3] Third method get a list of the last 10 values, sorted a certain filter in a specified file
